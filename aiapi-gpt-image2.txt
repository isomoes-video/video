中文标题：isomoes api 接入 GPT Image 2
English Title: GPT Image 2 Integration with isomoes api

本期视频介绍了 isomoes api 已经支持 GPT Image 2，并演示两种常见使用方式。第一种方式是通过网页工具直接使用图像生成能力。该网页项目基于开源项目二次开发，生成图片、请求状态等数据都会保存在用户本机浏览器的 IndexedDB 中，服务端不会存储图片，因此更强调本地优先和隐私保护。使用时需要配置站点 URL 和个人 API Key，接口选择 image，模型 ID 保持默认，超时时间可适当调大。完成配置后，可以在网页中输入提示词进行文生图，也可以添加附件实现图生图，并通过复用配置或编辑输出的方式对已有图片继续迭代修改。

视频还说明了 Codex CLI API 配置下的一些限制与参数选择，例如质量和压缩率不可调，但尺寸可以调整；分辨率过小或过大可能不支持，目前主要支持 1K 到 2K 之间的分辨率。如果只是想快速查看效果，可以使用 auto 尺寸，让系统自动适配输出图片的长宽比。

第二种方式是通过 API 进行更进阶的接入。视频以一个“根据字幕生成视频简介，再根据简介生成视频封面图”的项目为例，展示如何让 agent 读取视频简介，生成适合 GPT Image 2 文生图的提示词，再调用接口生成封面缩略图。这种 API 调用方式可以接入用户自己的应用、软件或工作流中。最后，视频补充了 GPT Image 2 的生成成本和速度示例：单次请求通常在两分钟以内，单张图成本大约为零点几元，相比部分国产文生图服务价格更低，同时质量也较好。
