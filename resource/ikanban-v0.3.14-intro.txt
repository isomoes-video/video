中文标题：iKanban v0.3.14：面向 OpenCode 的多智能体工作台
English Title: iKanban v0.3.14: A Multi-Agent Workspace for OpenCode

本期视频介绍 iKanban 从 v0.3.1 到 v0.3.14 的更新，以及项目重新投入维护的原因。由于 OpenCode 原生终端界面不便于在同一工作流中管理多个 Session 和多个 Agent，iKanban 继续以可视化工作台的形式提供多会话管理能力。本轮更新没有引入大型核心功能，而是通过十三个小版本集中打磨交互、审阅流程、界面一致性和多机操作体验。

主要变化包括移除内置任务状态图，将长任务规划交给 OpenCode 插件和 Skill；升级 Diff 审阅接口，提供类似 GitHub Pull Request 的逐文件审阅与折叠流程；重新设计对话区域的阅读宽度，并用图标和徽章区分 Shell、Patch、Explore 等工具调用，同时显示每次操作耗时，方便审计执行历史与定位 Agent 工作瓶颈。输入区域也支持大屏展开，以便编写复杂的长提示词；桌面端和移动端则统一为更精简的终端风格。

视频还演示了以浏览器标签隔离不同 OpenCode Server 的方式，让用户同时控制本地与远程机器，并在每台机器上运行多个独立 Session。通过加密通道、服务器 URL 和认证信息，iKanban 可以连接远程设备，并在移动端实现不受地点限制的 Web Coding。最后，视频回顾了 Timeline 版本回滚、快捷键、响应式适配等能力，说明当前版本已覆盖作者大部分日常工作场景，重点提升了多 Agent 并行、对话追踪和代码审阅体验。
