中文标题：录屏剪完还要手工发布？mvideo 用 Agent 自动跑完全流程
English Title: Still Publishing Screen Recordings by Hand? Let mvideo Agents Run the Entire Workflow

这期视频介绍 mvideo 0.1.2：一个面向口播和录屏视频的 Agent-first 发布工具。视频先回顾了 Web 视频编辑方案在长视频编解码性能和技术栈兼容性上的限制，再说明为什么项目转向 CLI，并将裁剪、音量标准化、背景音乐混合、字幕生成、简介与章节整理、封面制作等常用操作组织成可由 AI Agent 调用的分阶段工作流。

视频重点演示了完整发布流程如何从 prompts/README.md 统一编排各阶段：Agent 检查素材和工具，分析并处理音频，通过 DashScope ASR 生成和校正 SRT，从字幕中选择开场精彩片段并结合画面验证，在一次渲染中拼接预告和烧录字幕，最后根据成片字幕生成双语标题、简介、章节和 16:9 封面。每一步都要求验证产物，既可运行完整流程，也能单独调用某个阶段，从而减少录屏发布中的重复手工操作。
