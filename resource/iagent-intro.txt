中文标题：iAgent 把终端搬进浏览器
English Title: iAgent: Claude Code in the Browser

这期视频介绍了作者新封装的一个工具 iAgent。开篇先交代背景：之前做的爱看板、iPad 等方案都存在一些问题，而团队最近转向了用终端的方式来使用 Claude Code，但又希望能在浏览器里操作。作者调研了现有方案，比如一个 7k star 的 Go 语言项目，它基于 tmux 管理多个后端终端，每个终端对应一个 git worktree，每个 worktree 对应一个 Claude 实例，从而实现并行 agent——这其实和 Claude 自带的 Claude agents / agent views 以及动态工作流（dynamic workflow）思路一致。由此引出一个想法：能不能把终端直接搬进浏览器。八个月前已有人做过类似项目，但已停更、只有 77 star、功能也不完善，作者沿用这套技术栈做了探索，于是有了 iAgent。

随后是功能演示。iAgent 以路径为核心：新建一个 workspace 对应一个路径，也就是当前项目；每个项目下可以开多个 session 并行对话与运行任务。需要编排时，可以用上期讲的 auto code / dynamic workflow 让 AI agent 自动编排，也可以手动开多个互不冲突的 session。整体是一个最小化实现，支持同时运行多个项目、每个项目多个 session，目前暂不支持 agent views。基础设置包括调整终端字体大小、隐藏侧边栏以获得沉浸式体验。

作者还对比了与爱看板的区别：爱看板基于 SDK、依赖 agent 运行时对外暴露的 API，集成复杂度较高；而 iAgent 直接把终端搬过来，所有基于终端的操作无需迁移，相当于在浏览器里有了原生终端。团队特意让 Claude Code 优化性能，session 之间切换丝滑、新建 session 启动很快。交互上加了上下滑动等快捷键：在终端高亮聚焦时所有按键等价于在终端中使用；按 Tab 可切换到浏览器的 view 按键（super keys），再按 f 即可模拟点击、滑动以及在标签间切换。最后作者总结这次最大的不同在于把终端原生的操作体感迁移到了浏览器，兼容性和体验都不错，并邀请大家点 star、提意见。
