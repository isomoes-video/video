中文标题：告别终端 newsboat：自研轻量级全键盘 Web 版 RSS 阅读器 iReader
English Title: Goodbye Terminal Newsboat: iReader, a Lightweight Keyboard-Driven Web RSS Reader

本期视频介绍我自己做的一个小工具——iReader，一个轻量级、基于 Web 的 RSS 阅读客户端。它以 npm 包 ismoes ireader 对外发布，当前版本 0.2.1，作者觉得这个版本已经可以满足日常使用，因此制作本期视频做一个整体 overview，介绍它的由来、设计、特性以及后续规划。它的核心思路是：把终端阅读器熟悉的全键盘操作搬到浏览器里，同时解决终端阅读的两大痛点。

视频开头先讲做这个项目的动机。此前作者一直在终端里使用 newsboat 来读 RSS，但用了一段时间发现两个绕不过去的痛点。第一，很多信息源（比如 GitHub 官网、各种博客）里有大量 figure 和图片，而 newsboat 在终端里对图片的支持很差，基本看不了。第二，作者常读英文博客，想顺手翻译个别生词，但要在终端里取出文本去翻译非常费劲，要么得改 API，要么得想办法把终端内容捕获出来，体验都不好。正是显示图片不便和翻译不便这两个问题，让作者萌生了换条路的念头：能不能做一个基于 Web 端的、轻量的 RSS 阅读器。

在设计上有两个明确诉求：一是架构尽量像旧项目一样简单；二是因为作者本身是终端用户，要把过去在 newsboat 里很熟悉的那套键盘操作原样映射过来，于是就有了 iReader。

随后视频介绍启动方式与整体架构。启动很方便，直接用 npx 就能拉起这个项目，因为它本身就是 CLI 终端工具，可以设置几个 option 指定在哪个终端下启动；所有内容都存在本地的 db 里，这一点也和 newsboat 的设计相似；订阅源可以通过 OPML 这一 RSS 标准格式导入；如果要做二次开发，文档里也介绍了怎么启动。

接着是本视频的重点——三栏布局与全键盘交互。界面采用经典的三栏布局：左栏是订阅源以及已读/未读文章的概览，中间栏显示文章列表，最右栏显示具体的文章内容。导航完全贴近 vim：用 h 向左、l 向右切换三栏焦点，j/k 在各栏内上下移动，仅靠 hjkl 就能完成软件的大部分操作，并支持跳到开头和末尾。文章相关快捷键包括：m 标记已读/未读（从一篇未读移到下一篇时也会自动标为已读），n 跳到下一篇未读，s（star）收藏好文章，还能把整个 feed 一键标记为全部已读；刷新方面，大写 R（Shift+R）刷新全部 feed，小写 r 单独刷新某一个来源；在正文里遇到链接想跳转，可以用井号键配合数字（如 #2）直接打开对应原文链接，跳到原文页面查看。此外还支持全局文字搜索定位文章、dark 与 light 两种主题，以及订阅源的导入与导出。作者也顺便推荐了自己最近常用的几个来源，主要是 AI 资讯、科技新闻、GitHub 新项目以及一些长文博客，并给出了对应链接。

关于后续规划：目前每个 RSS 来源都是独立的一个框，作者想给它加一个二次分组的功能，比如把所有 blog 类内容归到一起、把所有实时短新闻归到一起，这可能是后面版本要加的新特性。

最后总结做 iReader 的三点主要原因：一是全键盘方式可在 Web 端使用；二是可以正常查看图片（这是 newsboat 做不到的）；三是借助浏览器已有的翻译插件，读英文文章时能更快更好地翻译，并方便与其他工具做二次集成。作者表示初步试用两三天体验不错，欢迎感兴趣的朋友关注并 star 仓库。感谢观看。
